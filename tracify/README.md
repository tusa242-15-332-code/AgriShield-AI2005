# 📂 Tracify — AgriShield AI Project Intelligence Hub

> **Purpose:** This folder is the single source of truth for understanding, maintaining, and evolving AgriShield AI. Every document here tracks architecture decisions, development status, future roadmaps, known gaps, and technical debt so that any team member — present or future — can onboard fast and ship with confidence.

## How to Use This Folder

1. **New team member?** Start with `PROJECT_OVERVIEW.md` → `ARCHITECTURE_DEEP_DIVE.md` → `DEVELOPER_GUIDE.md`
2. **Planning a sprint?** Check `MODULE_STATUS.md` + `ROADMAP.md` + `TECH_DEBT.md`
3. **Touching ML models?** Read `ML_MODEL_REGISTRY.md` + `DATA_LINEAGE.md`
4. **Preparing for deployment?** Review `SECURITY_AND_COMPLIANCE.md` + `TECH_DEBT.md`
5. **Updating the project?** Log every significant change in `CHANGELOG.md`
